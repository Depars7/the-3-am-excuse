A hardware wallet refuses to sign at 3 AM — the owner who actually reads the address went to bed hours ago, and the one holding it now just tried to send rent money to a frog. A tiny stdlib-only Python program writes that one 147-character line to `/output/entry.txt`, no trailing newline, no emoji, no quotation marks.

## Run it

```sh
python3 main.py
```
